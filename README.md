# IB2AD0 Data Science and Generative AI: Directed Learning

Notebooks from the Warwick Business School module IB2AD0 (Data Science and Generative AI), worked through in Google Colab. Each notebook is the course notebook with every cell run and my exercise work added at the end.

## Notebooks

| Notebook | Topic | Exercise |
| --- | --- | --- |
| [2.02 Joining DataFrames](2_02_Joining_DataFrames.ipynb) | Combining dataframes with `merge` | Compared left, inner, right and outer joins and what each keeps or drops |
| [2.03 Calculated Fields, Indexing and Subsetting](2_03_Calculated_Fields_Indexing_and_Subsetting.ipynb) | Calculated columns and filtering rows | Added a markup column to the product data and subset orders under 20 pounds |
| [2.04 Transforms and Concatenation](2_04_Transforms_and_Concatenation.ipynb) | Transforming and stacking data from an Excel file with several sheets | Compared mean and median monthly sales by location |
| [2.05 Exploratory Data Analysis](2_05_Exploratory_Data_Analysis.ipynb) | A full EDA on a student performance dataset | None, run end to end |
